「賢いモデルを小さくする」研究の蒸留の入口。教師にするモデルが、今までの評価で使っていない規程と問で正しく判断できるかを確かめる。2026-11-02 の協議（Astra）と本人の承認（「それで進めて」）で決めた。

## 作り方

1. `corpus/`: 今までの評価（`evaluation/corpus`・`evaluation/v2/corpus_nx_*`）で使っていない架空の規程 6 本を新しく書いた
2. `rules.py`: 規程の数の条件を 1 つずつ関数にし、問に入れた事実（facts）だけから結論を出す。分からない事実は 3 値（True/False/None）で扱い、None が残れば「判断できない」
3. `questions.py`: 96 問（境目 48・言い換え 24・例外と保留 24）。正解は `rules.py` が出し、手で書かない
4. 点検（`check_blind.py`）: 正解・facts・区分を伏せた問と規程だけを別の確認役（Codex・読み取り専用）に解かせ、コードの正解と照合した
   - 1 回目: 結論の食い違い 4 件（T038・T039・T052・T076）。どれも問の聞き方があいまいで、ほかの条の手続きまで含めて読めた。問の文を直した（他に「あいまい」と挙がった T043・T044・T064・T065 も同じ向きで直した）
   - 2 回目: 直した後の全 96 問を新しく解かせ、食い違い 0 件・根拠の条の不一致 0 件・あいまいな問なし
   - 記録は `blind_check/`
5. 封: `sealed/questions.jsonl` と `sealed/manifest.json`（問題集・6 規程・指示文の sha256）。`test_teacher_check.py` が、封の後に 1 文字でも変われば落ちる
