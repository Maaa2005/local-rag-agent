# 転勤支度金規程

第1条（目的）この規程は、転勤に伴う支度金の支給について定める。

第2条（対象）支度金は、会社の命令による転勤で、旧住所から新勤務地までの片道の経路距離が50 km以上のものについて支給する。本人の希望による異動には支給しない。

第3条（上限額）支度金の上限額は、別表の基本額に、次条の家族加算額及び第5条の加算額を加えた額とする。

第4条（家族加算）新勤務地へ同伴する家族1人につき30,000円を加える。加算は4人までとする。
2 単身で赴任するときは、前項の「同伴する家族」を「扶養する家族の半数（1人未満の端数は切り捨て）」と読み替える。

第5条（急な赴任）内示の日から赴任日までの日数（赴任日の日付から内示の日の日付を引いた日数）が14日未満のときは、50,000円を加える。

第6条（再度の転勤）支度金を支給した前回の赴任日の1年後の同日より前に再び転勤となったときは、第2条にかかわらず、支給しない。

第7条（可否）申請額が上限額以下のときは支給し、上限額を超えるときは却下する。上限額の一部だけを支給することはしない。

別表

| 片道の経路距離 | 基本額 |
|---|---|
| 50 km以上200 km未満 | 100,000円 |
| 200 km以上500 km未満 | 150,000円 |
| 500 km以上 | 200,000円 |
