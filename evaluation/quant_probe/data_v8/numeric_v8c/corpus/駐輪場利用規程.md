# 駐輪場利用規程

第1条（目的）この規程は、本社駐輪場の利用の許可について定める。

第2条（用語）この規程において、次の各号に掲げる用語の意味は、当該各号に定めるところによる。
(1) 通勤距離 自宅から勤務地までの片道の最短の道路経路の距離をいい、0.1 km単位とし、0.1 km未満は切り捨てる。
(2) 新規 初めての利用の申請をいう。
(3) 更新 現に許可を受けている者が、翌年度も同じ車両で続けて利用するための申請をいう。

第3条（利用の資格）新規及び更新の申請者は、次の表の区分に応じ、通勤距離が表の距離以上のときに、利用を許可する。

| 区分 | 排気量 | 通勤距離 |
|---|---|---|
| 自転車（電動アシストを含む。） | 排気量なし | 2.0 km以上 |
| 原動機付自転車 | 50 cc以下 | 3.0 km以上 |
| 小型二輪車 | 50 ccを超え125 cc以下 | 5.0 km以上 |

2 排気量が125 ccを超える二輪車は、利用できない。排気量は、1 L = 1,000 ccとして換算する。

第4条（距離の特例）身体障害者手帳の交付を受けている者は、前条第1項の通勤距離にかかわらず、利用を許可する。ただし、前条第2項は適用する。手帳の交付の申請中の者は、交付を受けた者に当たらない。

第5条（1人1台）許可は1人につき1台とする。別の車両で既に許可を受けている者には、許可しない。

第6条（有効期間）許可の有効期間は、4月1日から翌年3月31日までとする。

第7条（更新の期限）更新の申請は、有効期間の満了日の30日前までにしなければならない。30日前の日の当日は間に合う。期限を過ぎた更新の申請は、受け付けない。
