# 騒音作業場保護具規程

第1条（目的）この規程は、騒音のある作業場での聴覚保護具（耳栓又は耳覆い）の着用と聴力検査について定める。

第2条（適用）この規程は、会社が騒音管理区域に指定した作業場に適用する。指定のない場所には適用せず、保護具の着用は要らない。

第3条（騒音の測り方）
1 騒音は、作業者の耳の位置で、A特性の騒音レベル（単位 dB）で測る。小数第1位まで読み、丸めずにそのまま用いる。
2 作業者が遮音ブース（扉を閉じた状態のもの）の中で作業するときは、ブースの中で測った値を、その作業者の騒音とする。扉を開けたまま作業するときは、ブースの外の値を用いる。

第4条（着用の基準）
1 作業者がその日に騒音のある場所にいた時間（休憩を除く。）を、別表の騒音レベルの区分ごとに集計し、区分ごとの時間を許容時間で割った値を合計する。この合計を「ばく露指数」という。
2 ばく露指数が1以上のときは、聴覚保護具を着用する。1未満のときは、着用は要らない。
3 85 dB 未満の場所にいた時間は、ばく露指数に入れない。

第5条（100 dB 以上）作業者の騒音が100 dB 以上の場所では、前条にかかわらず、いた時間の長さにかかわらず着用する。

第6条（聴力検査）
1 聴力検査は、その作業者が働く場所の騒音の最大値が91 dB 以上のときは6か月ごと、91 dB 未満のときは12か月ごとに受ける。
2 前回の検査日から6か月又は12か月を経過した日の応当日を、検査の期限とする。期限を過ぎても検査を受けていない作業者は、85 dB 以上の場所では、第4条にかかわらず着用する。期限の当日までは、期限を過ぎていないものとする。

別表（第4条関係）

| 騒音レベル | 許容時間 |
|---|---|
| 85 dB 以上 88 dB 未満 | 8時間 |
| 88 dB 以上 91 dB 未満 | 4時間 |
| 91 dB 以上 94 dB 未満 | 2時間 |
| 94 dB 以上 100 dB 未満 | 1時間 |
