# 育児短時間勤務規程

第1条（目的）この規程は、子を養育する社員の短時間勤務について定める。

第2条（対象）この規程は、子と同居して養育する社員に適用する。子と別に暮らしている社員には適用せず、短時間勤務は認めない。

第3条（子の年齢）短時間勤務は、子が3歳に達する日（3歳の誕生日の前日）までの間に限り、利用できる。短時間勤務を始める日が、この日より後のときは、認めない。

第4条（勤務時間）短縮後の1日の勤務時間（休憩を除く。）は、5時間以上6時間以下とし、30分単位で定める。この範囲に入らないときは、認めない。

第5条（申出の期限）
1 申出は、短時間勤務を始める日の1か月前の日までに、書面で行う。
2 前項の「1か月前の日」は、始める日の属する月の前月の同じ日とし、その日が無いときは前月の末日とする。
3 申出が期限を過ぎたときは、認めない。

第6条（期限の特例）配偶者の死亡、又は入院を伴う負傷若しくは疾病により、予定していた養育ができなくなったときは、前条第1項の「1か月前の日」を「始める日の前日」と読み替える。

第7条（賃金）短時間勤務の期間中の賃金は、勤務時間に応じて減額する。
