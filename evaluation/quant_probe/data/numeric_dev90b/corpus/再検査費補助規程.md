# 再検査費補助規程

第1条（目的）この規程は、定期健康診断で再検査が必要とされた社員の再検査費用の補助について定める。

第2条（対象者）補助の対象は、定期健康診断で「要再検査」と判定された社員に限る。自分の判断で受けた追加の検査は、対象としない。

第3条（受診期限）結果通知書の日付の翌日から数えて30日以内に再検査を受診した場合に、再検査費用の全額を補助する。1回につき1万円を上限とする。

第4条（申請期限）補助の申請は、再検査を受診した月の翌月の末日までに行う。

第5条（3月に受診した場合）ただし、3月に受診した場合の申請期限は、年度末の経理締めのため、同年の3月31日とする。
