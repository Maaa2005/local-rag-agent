# 文書廃棄規程

第1条（目的）この規程は、社内文書の保存期間と廃棄の手続について定める。

第2条（対象）この規程は、総務部の文書管理台帳に登録された文書に適用する。台帳に登録されていない文書は、登録が済むまで廃棄してはならない。

第3条（保存期間）保存年数と基準日は、文書の種類ごとに別表のとおりとする。

第4条（起算と満了）保存期間は、別表の基準日が属する年度の翌年度の4月1日から起算する。年度は4月1日から翌年3月31日までとする。満了日は、起算日から保存年数を経過する年の3月31日とする。

第5条（廃棄）満了日の翌日以後の文書で、所管部長の承認を得たものは、廃棄できる。満了日の当日は廃棄できない。

第6条（複製）原本が別に保管されている複製は、保存期間及び前条の承認にかかわらず廃棄できる。

第7条（法的保全）法務部が保全を指定した文書は、複製を含め、前2条にかかわらず、指定が解除されるまで廃棄してはならない。

第8条（方法）紙の文書は溶解又は裁断により、電子の文書は復元できない方法により廃棄する。

別表

| 文書の種類 | 保存年数 | 基準日 |
|---|---|---|
| 会議議事録 | 3年 | 作成日 |
| 経費精算書 | 5年 | 作成日 |
| 稟議書 | 7年 | 決裁日 |
| 契約書 | 10年 | 契約終了日 |
