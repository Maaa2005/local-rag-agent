# リフレッシュ休暇規程

第1条（目的）この規程は、長く勤めた社員が取得できるリフレッシュ休暇について定める。

第2条（対象者）リフレッシュ休暇の対象は、正社員に限る。

第3条（勤続年数）休暇の開始日が属する年度（毎年4月1日から翌年3月31日まで）の4月1日の時点で、勤続が10年以上（120か月以上）あるときに取得できる。勤続は入社日から数え、1か月未満は切り捨てる。

第4条（申請の期限）申請は、休暇の開始日の14日前まで（14日前の日を含む）に行う。

第5条（転籍者の通算）ただし、グループ会社から転籍して入社した社員については、転籍前のグループ会社での在籍期間を勤続に通算する。これ以外の期間（派遣社員や業務委託として当社で働いた期間を含む）は通算しない。
