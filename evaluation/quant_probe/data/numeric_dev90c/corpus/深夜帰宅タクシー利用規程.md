# 深夜帰宅タクシー利用規程

第1条（目的）この規程は、深夜まで勤務した社員が帰宅に使うタクシー代の負担について定める。

第2条（対象）この規程は、所属長の承認を受けた時間外勤務のあとに帰宅する社員に適用する。承認を受けずに残っていた場合のタクシー代は、個人の負担とする。

第3条（時間帯）退社時刻が22時30分から翌日5時までの間（どちらの時刻も含む）であるとき、タクシー代を会社の負担とする。

第4条（金額）領収書1枚の金額が15,000円以下のときに限り、前条を適用する。15,000円を超えるときは、全額を個人の負担とする。

第5条（妊娠中の場合）ただし、妊娠中の社員本人については、第3条の「22時30分」を「21時」と読み替える。
