# 夜間勤務手当規程

## 第1条（目的）
この規程は、深夜の時間帯に勤務した社員に支給する夜間勤務手当について定める。

## 第2条（対象者）
手当の対象は、管理職を除く社員とする。管理職には役職手当を支給しているため、本手当は支給しない。

## 第3条（支給の条件と額）
22時から翌朝5時までの間に勤務した時間がある場合に、その時間に対して夜間勤務手当を支給する。22時より前の勤務時間は、手当の計算に含めない。手当の額は、その社員の時間給の25%に、22時以降の勤務時間（1分単位で計算）を乗じた額とする。

## 第4条（例外）
ただし、所定の勤務時間に22時以降の時間が含まれるシフト勤務者（夜勤担当）には、本手当に代えて夜勤手当（別規程）を支給し、本手当は支給しない。

## 第5条（事前承認）
手当は、上長が事前に承認した勤務に対してのみ支給する。承認を受けずに行った勤務は、手当の対象としない。

## 第6条（支払い）
手当は、勤務した月の翌月の給与と合わせて支払う。
