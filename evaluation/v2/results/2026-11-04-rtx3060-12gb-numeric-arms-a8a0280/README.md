## 読み方

- 安い腕 3 つは、N でも開発用でも結論が 1 問も変わらなかった。
- カード方式は N09・N11 の誤った断定を無くした。N09 は保留、N11 は正解になった。
- N09 の保留の原因: 値の 3 つ（勤続 6・出勤 90・全労働日 100）は正しく、モデルが文に無い欠勤日数を 100−90 で 10 と計算して埋めた。引用にその数が無いので検査が止めた（検査の働きどおり）。
- 値の一致: 枠で N 26/27（2 回とも）・開発用 30/30。問で N 11/12・開発用 24/24。カードに当たらなかった問は 0。
- 考える文の漏れ（llama.cpp #30256）: カードの抽出だけの回で 60 回中 0 回・打ち切り 0 回（出力の最大 159 トークン）。E4B・この版ではここでは再現しなかった。カードの回（検索あり）はこの数を記録していない。

## 時間とメモリ

- 見込み「時間は今と同じか短い」は外れた。カードは C より N で約 1.7 秒、開発用で約 0.9 秒長い。C の回答が結論の行だけ（6 トークン）なのに対し、抽出は中央値 54〜102 トークンを出すため。どの問も 15 秒の線の内（最大 5.509 秒）。
- 出力の速さ 79〜82 トークン/秒。GPU の最大 4,676〜4,709 MiB（起動前 1.4GB 前後を含む）。文脈あふれ 0・メモリ不足 0。入力の最大 1,967 トークン（N05）。
- 本体: llama-server 最大 4,012〜4,379 MiB、評価 約 1,820 MiB、Qdrant 約 120 MiB。回の中の空きの最小は 259〜931 MiB で、余裕は小さい。

- 50 問（Q・P・M8）と G0 は流していない。この結果は最終判定ではない。
