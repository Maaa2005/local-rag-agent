# ask90

架空の社内規程について、従業員の質問の場面を 90 個。問の文には事実の一部だけを書き、全部の事実は別に隠して持つ。AI が足りない事を聞き返し、本人が隠した事実から答える評価に使う。評価する側の実装を見ない別担当が作った。

## 内訳
規程 6 本（`corpus/`）× 15 場面 = 90。id は A001〜A090、順と選択肢の並びは乱数で混ぜた（`make_questions.py` の SEED）。

| kind | 数/規程 | 中身 |
|---|---|---|
| complete | 4 | 結論に要る事が文に全部ある。うち 2 問は言い換えの対（pair_id P1〜P6） |
| exc_hit | 1 | 例外が当たるのに文に無い。書かれた事だけで読むと逆になる |
| exc_miss | 1 | 同じ形で例外は当たらない。例外の話は文に無い |
| missing_one | 2 | 結論を割る事実がちょうど 1 つ文に無い |
| missing_many | 3 | 結論を割る事実が 2 つ以上文に無い |
| irrelevant_gap | 1 | 基準の事実が文に無いが、どの値でも結論は同じ |
| dont_know | 3 | 結論を割る事実を本人も知らない。正解は保留 |

dont_know を除く 12 場面の結論の向きは、規程ごとに 6 対 6。exc_hit と exc_miss は互いに逆の結論。

## ファイル
- `questions.jsonl`: id, question, rule_id, kind, should_hold, expected_conclusion, conclusion_options, group, pair_id, basis
- `facts.jsonl`: id, facts（全部の事実）, stated（文に書いた事実の名前）, unknowns（dont_know で本人が知らない事実と、あり得る値）
- facts の読み方: 値 `"不明"` は本人も知らない事実。`被災認定日`・`育休復職日` の null は当たらない事を示す。`検定履歴` は [受験日, 点] の配列。

## 作り方
1. 規程の文から場面の事実を決め、問の文を手で書いた（`make_questions.py`）。文に計算の要る書き方（時間と分、税抜き、週、和暦、窓の外の点）と無関係な数を混ぜた。
2. `check.py` が規程ごとの式 2 通り（f1 は上から順、f2 は妨げの列挙や別の計算）で、文に無い事実にあり得る値を全部入れて確かめる。
   - 全組合せで f1 と f2 が一致し、全部の事実で出した結論が正解と同じ
   - dont_know は unknowns の値だけで結論が割れる
   - missing_one は割る事実がちょうど 1 つ、missing_many は 2 つ以上、exc_* は欠けが例外の事実だけで結論が割れる
   - complete と irrelevant_gap は stated だけで結論が 1 つ。complete の欠けは例外の事実だけ、irrelevant_gap は基準の事実も欠ける
   - 文に書いた事実の語が文にあり、書いていない事実の語と数が文に無い（語の表で確かめる）
   - 件数・内訳・向き・対の事実の一致・最後の行の書式
3. `check.py` が誤りを見つける事を、写しに 8 種の壊し方（結論の反転、stated の水増し、unknowns の削り、stated の削り、事実の削除、例外を消す、文に語を足す、f2 を壊す）を入れて確かめた。全て止まった。

走らせ方（`PYTHONUTF8=1`）: `python make_questions.py </dev/null` のあと `python check.py </dev/null`。

## 限界
- 式 2 通りは同じ担当が書いた。規程の読み方そのものの誤りは、この再計算では見つからない。
- 「文に無い事を推測できない」は語の表で機械的に見ているだけで、自然さは手で読んで決めた。
- complete や missing_* は、割れを防ぐために例外が無い事を文に書く場面がある。exc_* は例外に触れない。文に例外の否定があるかどうかで、種類の見当がある程度つく。
- 問の文の中の接種日や届出日の妥当さは、規程の結論に関わる範囲だけを見ている。曜日や祝日は扱わない。

## 迷った所の決め方
- 海外出張の危険度は「出発日に最新のもの」で、出発前には定まらない。文には「出発日に最新のもの」と書き、確定した値として扱った。
- 接種費用の領収書の提出と振替の取得は、問の時点で先の事でも予定の日をそのまま事実とした。
- 語学研修の「復職後 1 年以内」は 1 年後の同じ日の扱いが規程に無いので、境目ちょうどの場面を入れていない。税抜きの 1.1 倍の端数も、端数の出ない額だけを使った。
