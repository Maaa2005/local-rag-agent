## 分かった事（12 問の試しで、結論ではない）
1. 道具は端から端まで動いた（固定 → 判定 → 比べる → 悪化した問の表）。判定できずは NJ-2 で 36 件中 1 件（事実の数が合わない返答）で、点から外して数を出した。
2. キーワードの点は、境目の誤り（X038）と結論の誤り（X048 の A'）を見逃した。必須の事実の点は両方を下げた。
3. **4B の判定役は書き落としに甘い。** 作業役の札では「理由を 1 文にすると点が下がる」が揺れより大きく出たのに、判定役では揺れの中だった。写しを求める直し（NJ-2）で差の向きは合ったが、一致は 72% のまま。「結論: …」の行を定型と付ける誤りも NJ-2 で残った（X048 の B）。この判定役の点だけで採用を決めてはいけない。
4. A/A の揺れの幅は 12 問では 0.1〜0.2 と大きい。小さい差を見るには問の数か K を増やす必要がある。

## 追記 2: NJ-3 と Swallow 8B（GPU・04:37〜04:50・本人「05:30 まで使って」）
NJ-3 = 写しの代わりに「その事実を述べた答えの文の番号」を挙げさせ、番号が無い「すべて/一部」を機械で「述べない」に下げる。Swallow 8B は `~/qp-data/models/swallow-8b-q8.gguf`（読むだけ）。GPU は 04:50 に下ろした。

どの判定役も「信じる差」にならなかった（作業役の札だけが −0.149 で信じる差）。

分かった事:
1. 8B にしても一致は 4B と変わらない（66〜72%）。大きくすれば直る、ではなかった。
2. 誤りの形は 2 つに分かれる。写しを求めると、写せずに正しい事実まで落とす（厳しい）。文の番号を求めると、事実を書いていない文の番号を挙げて満点にする（甘い）。
3. 一番多い誤りは「境目の数や日付を書かずに関係だけ書いた答え」を満点にする事。境目の語の検査を足すと一致は 79〜81% に上がる。**ただし札と keywords はどちらも作業役が「数値を書かなければ一部」という同じ考えで作ったので、この上がり方には自分の考えに合わせた分が入っている。** 本人か別の人の札で確かめるまで採らない。
