# C: 数の比べをコードでやる（設計・2026-10-24）

本人承認 10/24（`docs/v2-light-model-plan.md` §4）。線と今の 12 問（N）は変えない。

この文書と下の「言い回しの一覧」は、確かめ用の問（48 問）を作る**前**に固めてコミットする。確かめ用の問はこの一覧に合わせて書かない。一覧に無い言い回しが確かめ用に出たら、C は保留して今までどおりモデルだけで答える（それも結果として数える）。

## なぜ

10/24 の分類（`evaluation/v2/results/2026-10-24-n-error-classification/`）で、N の不一致 29 件すべてで規程の文は検索で取れ、結論の書式も崩れていなかった。落ちたのは数の判断（境目ちょうどの読み違い 16・大小の比べ違い 13）。比べる所だけをコードに任せる。

## 形

- 入る場所: `backend/app/services/llm.py` の `_build_messages`。参考情報と質問の間に `【計算の結果】` を足すだけ。結論はモデルが書く（「当てはまる/当てはまらない」をどの選択肢に結ぶかは規程の文の意味で決まるので、コードは決めない）。
- 設定で ON/OFF。既定は OFF（今までの測定と同じ動き）。
- 読んでよい物: 検索で取れた文と質問の文だけ。評価用の問の `boundary`・`expected_*`・`rule_quote` は読まない（関数の引数に入れない。テストで確かめる）。
- 出す文の例: `規程の「10万円を超える」に対し、質問の値 98,000円 は当てはまらない（98,000 ≤ 100,000）。`

## 手順

1. 質問から値を取る: 金額（円・千円・万円）、割合（%・割）、日数・回数・時間・人数、日付（年月日）。
2. 検索で取れた文を文ごとに切り、値と同じ種類の数・日付と、下の一覧の言い回しが並ぶ文を条件の候補にする。
3. 値の単位をそろえる（10万円→100,000 円、8割→80%）。日付の相対表現（翌月N日・当月末・発生日からN日以内）は質問の発生日から計算する。
4. 比べて「当てはまる/当てはまらない」を出す。

## 保留（何も足さずモデルだけで答える）

- 質問に値が無い。同じ種類で違う値が 2 つ以上ある（ただし相対日付の基準になる日・月〔発生日・購入日・誕生日・「10月分」など〕と、割合の分母〔「100点満点」など〕は、比べる値と競合する値に数えない）。
- 条件の候補が 0 個、または違う境目・違う向きの候補が 2 個以上ある。
- 単位がそろわない。営業日（暦が要る）。一覧に無い言い回し。
- 保留した時は記録に理由を残す。N の採点では保留も今の数え方どおり（モデルの答えで決まり、結論が無ければ不一致）。

## 開発用 24 問で足した決め事（10/24・確かめ用 48 問を流す前に固定）

- 違う境目・違う向きの候補が 2 個以上ある時: 質問と候補の文で、2 文字の並び（ひらがなだけの組は除く）が重なる数を数え、ただ 1 つ最大で 0 より多い候補だけ残す。同点か 0 なら保留。残した時は記録に印（tiebreak）を付ける。理由: 実際の検索では同じ種類の条件を持つ別の規程が一緒に取れ、字義どおりだと開発用で 9 問が保留になる見込み（字義どおりの実測は取っていない）。
- 質問の「最後の行」以降（答えの書式の指示）は値を取る対象と重なりの数えから外す。
- 日付: 質問の日付が 1 つなら絶対日付の条件だけ、2 つ以上か「N月分」があれば相対日付の条件だけを比べる。基準日と比べる日は、日付の前後の語（購入・発生など／提出・申請など）で分け、決まらなければ保留。
- 一覧の否定形は、表の動詞を直接打ち消した形（超えない・上回らない・下回らない・達しない・過ぎない・遅れない）だけ。
- 保留のまま: 営業日・「N日後」・N の無い「前日まで」・「毎月N日」・範囲の条件（以上…未満）・一覧に無い言い回し・年月だけの基準。
- 開発用 24 問での結果（検索の代わりに規程の全文と節ごとの切り出しの 2 通り）: 保留 0・比べた向き・境目・値・判定が 24/24 一致（うち 12 問は上の重なりで候補を絞った）。確かめ用は読んでいない。

## 言い回しの一覧（確かめ用の問を作る前に固定）

一般的な日本語の規程の書き方から集めた。否定形は向きを反転する。

| 向き | 数 | 日付 |
|---|---|---|
| `>` | 超える・超えた・超えて・超過・上回る・上回った・より多い・を超す | を過ぎた・を過ぎて・より後・遅れた・経過した後 |
| `>=` | 以上・達した・達する・下回らない | 以降・以後・から（期間の始まり） |
| `<` | 未満・下回る・下回った・満たない・より少ない・届かない | より前・前日まで・に先立って |
| `<=` | 以下・以内・超えない・上回らない・まで | まで・までに・以前・以内・を過ぎない |
