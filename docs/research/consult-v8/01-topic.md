背景: 版 7 の本番は全体「測れず」（8B の 2 つが基準の線 0 を割り、Gemma 4 12B は「決められない」）。問い（量子化で、規程の数値・境目・誤った断定は、perplexity や KLD が気づかない形で悪くなるか）は変えない。版 8 は結果を見た後の見直しなので、新しい 24 規程・360 問で測り直す。

点検してほしい点（各点に「このままでよい／直す（直し方）」を付けて）:
1. 線 0 を固定の率（正答 0.70・保留 0.50）から「向きを見分けている・保留を見分けている」（規程を単位にした符号入れ替えの片側検定 p < 0.001）に替える事。誤った「はい」の上限が保たれるという理屈（基準不適格は「気づかない」を出さない）は正しいか。基準の成績で選ぶ事による偏り（平均への回帰）は、この線なら小さいと言えるか。弱い基準（誤った断定が 25% を超える）を入れる事で、型 A・型 B の検定の前提（規程ごとの差が 0 の回りで対称）が崩れやすくなる具体的な筋はあるか。
2. 5 モデルにして 1 モデルの α を 0.0125 にし、「気づかない」2 つ以上で「はい」にする事。上限 5×0.0125/2 = 0.03125（見逃し 0）・4×0.0125 = 0.05（見逃し 1）の計算は正しいか。より検出力の高い決め方があるか（例: 3 つ以上で「はい」にして α を上げる）。
3. 会話の形の KLD を「答えの最初の 1 語・上位 100・360 問の平均」で取る事（5 章）。探索として意味のある量か。もっと良い取り方が、llama.cpp b11836 の道具を作り直さずにあるか。
4. GPU に載り切らないモデルの答えの回を全部同じ載せ方にする事（6 章）。
5. 新しい問を「判定の道具を見ない別担当（別の AI の作業役）が、前の問の README を仕様にして作る」事。版 7 と同じ作り方と言えるか。問を固定する前に見てよい事・見てはいけない事の線引きは足りているか。
6. このまま測ると結果が読めなくなる穴（特に、測った後に直せない物）。
